?? Instructions

  1. Ajoutez les utilisateurs avec leurs IP et fonctionnalités
  2. Cliquez sur "Exporter JSON"
  3. Remplacez le fichier data/access.json dans le dépôt GitHub
  4. Commit et push les changements
  5. Le plugin récupérera automatiquement les nouveaux droits
