Instructions

  1. Generez une cle API pour l'utilisateur
  2. Donnez la cle a l'utilisateur (ex: BV-K0ZA-H123-ABCD)
  3. L'utilisateur entre la cle dans le menu Better Visuals - API Key
  4. Cliquez sur "Exporter JSON"
  5. Remplacez le fichier data/access.json dans le depot GitHub
  6. Commit et push les changements
